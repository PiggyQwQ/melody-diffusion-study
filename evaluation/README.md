# 评测方法与结果

本目录汇总前向加噪理论校验、民歌重建、训练语料对照和无条件生成的实验结果。[字段说明](FIELDS.md)解释表格和图中的缩写、方法标识与统计口径。

## 实验设置

评测对象是 64 格的单声部旋律，每格记录休止、延音或音符起始的音高。词表包含 49 个音高以及 `REST`（休止）和 `HOLD`（延续上一事件），共 51 个符号。以中国民歌集成（ACFS）编码测试集为基础，先排除七首已有跨集合近重复记录的测试曲。每首保留曲目的窗口按起始小节排序后，取索引为窗口数整除二的一个窗口。共选出 419 首曲目的 419 个窗口，归入 416 个曲目组。[民歌数据](../data/acfs-v261103/split-encode-v1/) · [评测窗口清单](window_ids_test_frozen.txt)

离散加噪以概率 `ρ` 将每格替换为从词表均匀抽出的符号。重建实验使用五档累计混合量 `ρ = 0.10、0.25、0.50、0.75、0.90`，每档重复加噪五次，得到 10,475 份固定输入。各方法读取同一份加噪序列和噪声档位，以原曲为评分参照。随机重建方法对每份输入采样三次，模型结果汇总三个训练随机种子。传统基线包括直接解码、按单格符号频率作贝叶斯推断，以及一阶马尔可夫模型。单步网络基线使用同一网络一次预测，多步扩散则反复使用反向转移。

评测先对同一窗口的加噪和采样重复取平均，再逐级按窗口、曲目、曲目组汇总。置信区间来自 2,000 次曲目组层面的自助重采样。方法差异按共同曲目组配对。五声覆盖以固定音级集合 C、D、E、G、A 为主，另报告时值加权覆盖率和允许整体移调的最佳五音集合覆盖率。音程与音级分布的接近程度用 Jensen–Shannon（JS）距离衡量，距离越小表示分布越接近。

## 前向加噪理论校验

12 音级实验保留起音位置，以概率 `ρ` 把起音音级替换为均匀抽样。若原始覆盖率为 `p₀`，加噪后覆盖率的理论值为 `(1 − ρ)p₀ + ρ × 5/12`。即使初始覆盖率低于 5/12，也会向 5/12 靠近。完整词表包含 51 类，均匀替换仍有 1/51 的机会抽回原符号，所以期望错格率为 `ρ × 50/51`。

完整词表中 21 个符号属于目标五声音高。以固定格数为分母时，五声音高比例随混合量线性变化，纯噪声极限为 `21/51`。以加噪后起音数为分母时，分子和分母都随混合量变化，汇总条件比例的极限为 `21/49`。21 个噪声档各进行 50 次独立模拟，各通道和子集的模拟均值与理论值的最大绝对误差均小于 0.002。[理论与模拟图](figures/fig1_h1_theoretical_verification.png)

## 民歌重建

在混合量 0.50 时，多步扩散的逐格符号准确率为 **71.16%**，起音位置 F1（精确率与召回率的调和平均）为 **81.92%**。一阶马尔可夫后验采样对应为 **60.64%** 和 **67.07%**。曲目组配对差分别为 10.51 和 14.85 个百分点，95% 置信区间分别为 10.21–10.81 和 14.46–15.24 个百分点。[内容与节奏图](figures/fig3_h2_exact_and_rhythm.png)

同档的单格频率基线和扩散模型起音五声覆盖率均约 97%。将干净旋律的音高顺序打乱，覆盖率仍为 97.18%，对齐原起音的轮廓方向一致率降至 37.48%。混合量 0.90 时，单步最大后验预测的逐格准确率高于多步扩散，但起音数降至原曲的 43.16%。同档的多步扩散与单步随机采样逐格准确率接近，语料音程 JS 距离分别为 0.1064 和 0.4108。逐格恢复、节奏密度、五声覆盖和音程结构需要结合解读。[五声覆盖图](figures/fig4_h2_pentatonicity_and_gains.png) · [结构与单步预测对照图](figures/fig5_h2_structure_and_ablation.png)

## 训练语料对照

两套训练子集各含 25 个曲目组、1,323 个旋律窗口，起音密度相近，均沿用源谱的音高坐标。匹配民歌和粤语流行（Cantopop）训练集的固定五声覆盖率分别为 95.63% 和 50.02%，黑键音级起音占比分别为 0% 和 33.48%。图注中的「首调 1=C」指民歌数据中观察到的记谱特征。两种模型重建完全相同的受扰民歌窗口。在混合量 0.90 时，民歌模型与粤语流行模型的固定起音五声覆盖分别为 **96.86%** 和 **49.43%**，配对差为 47.43 个百分点，95% 置信区间为 46.90–47.93。粤语流行模型在允许整体移调时的最佳五声覆盖为 **80.95%**。记谱坐标和两库的音程分布均会影响固定音级覆盖，比较范围限于本实验的两套语料和训练设置。[语料对照图](figures/fig7_h3_prior_drift.png)

## 无条件生成

使用三个完整民歌训练模型从均匀噪声生成 300 段旋律。300 段均有效且各不相同，起音五声覆盖为 96.88%，音级与音程分布到冻结测试集的 JS 距离分别为 0.0247 和 0.1132。逐段与 32,656 个民歌训练窗口比较时，生成样本中没有精确匹配。允许整体移调后，生成样本与 300 个未见验证窗口到训练集的最小汉明距离中位数分别为 17 格和 16 格。两组中距离不超过 4 格的样本分别为 5 段和 4 段，双侧 Fisher 精确检验的 `p` 值为 1.0。该检验说明本次抽样中的相似程度，适用范围为所评模型、窗口及距离定义。[生成与最近邻图](figures/fig6_generation_and_memorization.png)

## 阅读与复核

表格是固定评测产出的汇总结果，可按方法、噪声档和指标直接检索。评测窗口清单保留原测试文件中的出现顺序，便于从训练数据以外的测试集恢复 419 个干净输入。完整重跑还需要从[训练与推理代码](https://github.com/PiggyQwQ/melody-diffusion-study/tree/25a99389b538cb9494bdfd2f47df4eb914bff9e4/training)生成受扰窗口、执行重建并重新汇总。图来自同批实验，保留原图编号。

网页的重合度 `n/64` 按解码后的发声状态计算，延音展开为实际音高，两格同为休止也计作吻合。正式表格的逐格符号准确率直接比较编码符号。语料对照正式评测以民歌为共同输入，网页还提供粤语歌曲输入的演示。
