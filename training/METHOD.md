# 方法（报告草稿）

本节描述训练组实现的离散扩散模型。代码在 `training/`：`diffusion.py`（转移矩阵、加噪、网络、反向采样）、`train.py`（训练）、`sample.py`（重建、一次预测消融、无条件生成、轨迹）。实现以组内参考实现 `reference_diffusion.py` 为基础重构，转移、网络与反向后验的定义与之一致。

## 1. 数据表示

每个样本是连续 8 个 2/4 小节的单声部旋律，按十六分音符切成 64 格，每格一个整数，词表大小 K = 51：

- `0` REST：从该格开始休止；
- `1` HOLD：延长前一格的发声或休止；
- `2…50`：新起音，MIDI 音高 = 整数 + 36（MIDI 38–86）。

一段旋律记为 x_0 ∈ {0,…,50}^64。REST 与 HOLD 和音高一样参与加噪和损失。

## 2. 前向加噪过程

取 T = 100 步。令 U = 11ᵀ/K 为每项均为 1/51 的矩阵，单步转移矩阵为

Q_t = (1 − β_t) I + β_t U，β_t = 1/(T − t + 1) = 1/(101 − t)，t = 1,…,100，

其中 Q_t[i, j] = p(x_t = j | x_{t−1} = i)。各格独立转移：以概率 1 − β_t 保留当前符号，以概率 β_t 从 51 类中均匀重抽（可能抽回原符号）。

## 3. 累计转移的闭式解

由于 UU = U、IU = UI = U，形如 (1 − a)I + aU 的矩阵相乘满足

[(1 − a)I + aU][(1 − b)I + bU] = (1 − a)(1 − b) I + [1 − (1 − a)(1 − b)] U。

因此 Q̄_t = Q_1 Q_2 ⋯ Q_t = (1 − ρ_t) I + ρ_t U，其中

1 − ρ_t = Π_{s=1}^{t} (1 − β_s) = Π_{s=1}^{t} (100 − s)/(101 − s) = (100 − t)/100，

即 ρ_t = t/100。于是可以一次抽样得到 x_t：每格以概率 1 − t/100 保留 x_0，以概率 t/100 从 51 类均匀重抽。期望的实际改变比例为 ρ_t · 50/51。t = 100 时 Q̄_100 = U，x_100 与 x_0 无关，各格独立均匀分布，这就是生成的起点。

代码中有三项测试检查这些关系：闭式 Q̄_t 与 Q_1⋯Q_t 逐步连乘在双精度下一致（t = 1…100）；按闭式一次抽样与按 Q_t 逐步前推得到的 x_t 分布一致（t = 10、50、90，各 200,000 个样本，卡方检验）；两者都与 Q̄_t 的理论行一致。

## 4. 网络

去噪网络 f_θ(x_0 | x_t, t) 是双向 Transformer 编码器：

- 输入：符号嵌入（51 类）+ 位置嵌入（64 格）+ 扩散步嵌入（t = 0…100），三者相加；
- L 层标准 Transformer 编码层（多头自注意力 + 前馈，GELU，dropout 0.1，post-LN，PyTorch `nn.TransformerEncoderLayer`），注意力头数 4，前馈宽度为 4 倍嵌入宽度；
- 输出：每格一个 51 维 logits，softmax 后即对 x_0 该格类别的预测分布。

网络只接收 x_t 和 t，不接收干净序列，也不知道哪些格被替换过。层数和宽度由第 2 步验证集比较确定，见第 7 节。

## 5. 训练目标

每次更新取一批干净窗口 x_0，每段独立抽 t ~ Uniform{1,…,100}，按闭式 Q̄_t 抽 x_t，最小化全部 64 格上的交叉熵

L(θ) = E_{x_0, t, x_t} [ −(1/64) Σ_{j=1}^{64} log f_θ(x_0^j | x_t, t) ]。

这是研究计划采用的**简化 x_0 交叉熵目标**。它没有完整复现 D3PM（Austin 等，2021）原论文的全部目标：原论文以变分下界 L_vb 为主，并可加辅助交叉熵项（混合损失）；本实现只用后者形式的 x_0 预测交叉熵，不计算各步 KL 项，也没有复现原论文的网络结构和噪声日程比较。

验证损失使用固定受扰：验证集每个窗口在 t = 10、25、50、75、90 各加噪一次（固定种子 9182，与参考实现相同的抽样顺序），计算同一交叉熵并对五个 t 取平均。

## 6. 反向采样

给定 x_t 与 x_0 时，前向过程的后验为

q(x_{t−1} = i | x_t = j, x_0 = k) = Q_t[i, j] Q̄_{t−1}[k, i] / Q̄_t[k, j]。

用网络预测的 f(k) = f_θ(k | x_t, t) 对 x_0 求和，得到反向一步的转移概率

p_θ(x_{t−1} = i | x_t = j) = Σ_k f(k) Q_t[i, j] Q̄_{t−1}[k, i] / Q̄_t[k, j]。

由于 Q̄_{t−1} Q_t = Q̄_t，上式对 i 求和恰为 1。各格条件独立地按此分布抽样，所有位置都允许更新；网络在每一步看到的是整段当前状态，因此各格的分布依赖整段上下文。重复 t, t−1, …, 1，得到 x_0。测试把实现与逐格暴力贝叶斯计算（先算联合概率再归一化）对比，t = 1、2、10、25、50、75、90、99、100 时误差小于 10⁻⁶，每行和为 1。

- **重建**：从评测组给出的受扰 x_t 出发反向到 0，每份 x_t 采样 3 次。
- **一次预测消融**：同一网络只在 x_t 上前向一次，逐格取 argmax（`oneshot_argmax`）或从 f_θ 独立抽样（`oneshot_sample`），用于区分多步反向过程本身的贡献。
- **无条件生成**：从 64 格独立均匀的 x_100 出发反向到 0。

解码时，若首格为 HOLD（没有可以延长的前一状态），改为 REST，并记录 `leading_hold_repaired`；没有任何发声音符时记 `has_sounding_note = false`。除此之外不对采样结果作任何修改，例如不删除五声音集合之外的音。
