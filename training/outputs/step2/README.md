## 过拟合检查（ACFS 训练集前 64 个窗口，dropout 0）

“记忆化下限”是完全记住这 64 个窗口的模型在相同受扰下的精确后验交叉熵（`memorizer_floor.json`）：t = 1…100 平均 0.1274；t = 10、25、50、75、90 分别为 1.1×10⁻⁶、1.0×10⁻⁷、0.00034、0.0110、0.578。

| 目录 | 网络、步数 | 训练损失（最后一个记录区间内随机 t 批次的均值） | 固定受扰训练集 CE：t=10 / 25 / 50 / 75 / 90 | 耗时 |
| --- | --- | ---: | --- | ---: |
| `s2-overfit-acfs_full-64win-L2-W64` | 2×64，6,000 | 0.516 | 0.0913 / 0.216 / 0.432 / 0.763 / 1.037 | 171 s |
| `s2-overfit2-acfs_full-64win-L2-W64-40k` | 2×64，40,000 | 0.275 | 0.0019 / 0.0066 / 0.0652 / 0.415 / 0.918 | 966 s |
| `s2-overfit3-acfs_full-64win-L4-W128-20k` | 4×128，20,000 | 0.175 | 0.00016 / 0.00025 / 0.0020 / 0.099 / 0.753 | 1,861 s |

第一次（6,000 步）没有达到标准。4×128 跑 20,000 步后，t ≤ 50 的训练集 CE 不超过 0.002，接近 0；随机 t 的训练损失 0.175，仍比下限 0.127 高约 0.05，差距集中在 t ≥ 75。三次的验证 CE 都随训练上升（见各 `train_log.csv`），符合记忆训练集的预期。
